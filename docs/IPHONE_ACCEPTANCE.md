GitHub Pagesへの公開と「Webアプリとして開く」をONにする手順は [iPhone導入README](GITHUB_PAGES_IPHONE.md) を参照してください。

記録欄: iPhone機種 / iOSバージョン / Safariバージョン / 配置URL / 確認日。

テストには消えてもよい研究データを使い、既存データがある端末では先に完全バックアップを保存してください。

## 初回とオフライン

- [ ] 安定したHTTPS URLをSafariで開き、4桁PINを確認入力付きで設定できる。
- [ ] 永続ストレージの結果とバックアップの案内を確認できる。
- [ ] ホーム画面に追加して起動できる。
- [ ] 「Webアプリとして開く」をONにして追加し、アイコン側でオンライン初回起動を完了する。
- [ ] 機内モードでアプリを終了・再起動して、PIN解除後に使える。
- [ ] オフラインでSeries作成、Card追加、Prompt編集、画像追加、お気に入り、検索、削除・Undoができる。

## CardとOriginal

- [ ] A-000へ写真5枚を一度に追加できる。失敗した画像があるときは成功分と失敗分を区別できる。
- [ ] TREEではCardが1つ、IMAGESでは画像が5つ表示される。
- [ ] JPEG、PNG、HEICで試し、Originalを保存し直して元ファイルのバイト数・SHA-256を比較する。
- [ ] HEICのサムネイルや描画に失敗してもOriginalを取り出せる。
- [ ] Cover変更、画像順序、差し替え、最後の画像の削除禁止が機能する。
- [ ] 原本の共有・Files保存・写真への保存を確認する。

## TREE

- [ ] Seriesごとに独立したCanvasとviewportを持つ。
- [ ] 1本指でCanvasをpan、2本指でpinchできる。
- [ ] Card上ですぐ動かす操作はCanvasのpanとなり、Cardは移動しない。
- [ ] 長押しした後だけCardを移動でき、Undo/Redoが効く。
- [ ] 拡大・移動した位置からDetailを開閉する操作を20回繰り返してもviewportが変わらない。
- [ ] TREEでページ本体が1pxもスクロールしない。上下端・Safariのバー表示変化でも確認する。
- [ ] 縦横回転してもCard座標が変わらず、操作領域がsafe-areaに収まる。
- [ ] 複数親、Primary Parent切替、Reference接続、線色変更ができ、Parent循環は拒否される。

## Gallery / Detail / HOME

- [ ] 写真一覧を素早くスクロールしても画像が無制限にDOMへ追加されない。
- [ ] Series・Root/Child・お気に入り・新旧順の切替が正しい。
- [ ] Viewerでスワイプ、拡大、共有、Promptコピーを行える。
- [ ] Detailから戻ったときGalleryのスクロール位置が保持される。
- [ ] HOMEのSeriesを長押しで並べ替え、再起動後も並び順が残る。
- [ ] 長いPrompt、検索、日本語、ダークモードで表示・操作を確認する。

## バックアップと復元

- [ ] 複数Series・5枚画像のRoot・派生Card・複数親・Reference・タグ・評価・独自座標を含める。
- [ ] 全PartをFiles/iCloud Driveへ保存し、各Partの保存完了を確認する。
- [ ] 16MiBを超えるデータで複数Partが生成され、生成中もメモリ不足で落ちない。
- [ ] テスト用の別ブラウザ/端末でPIN設定後、全Partから復元できる。
- [ ] 画像のSHA-256、Prompt、親子関係、タグ、評価、Card座標、viewportが一致する。
- [ ] Part不足・破損を拒否し、現在のデータを消さない。
- [ ] 復元後も端末のPINが維持される。

## 保護・容量・リセット

- [ ] バックグラウンドへ移ると画像やPromptを隠す。短時間で戻ると編集状態を保持する。
- [ ] 5分間無操作、手動ロック、再読み込みでPINが必要になる。
- [ ] PINの誤入力が続くと待機時間が表示される。
- [ ] 容量不足時に既存画像を壊さず、失敗を明示する。
- [ ] 更新案内で未保存の編集を確認してから更新できる。
- [ ] 同じGitHub Pages URLへ再deployし、「更新」後もPIN・Original・Prompt・TREE配置が残る。
- [ ] バックアップ済みテストデータでリセットを試し、DELETE入力と確認後に初期状態へ戻る。

未確認項目をPASSに変更する場合は、機種・OS・確認日・結果をこの文書へ記録してください。
